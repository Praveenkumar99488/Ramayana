# Ramayana Digital Library

A responsive single-page website to read, search and listen to the Ramayana (English translation, 17,925 verses).

**Tech:** HTML, CSS, vanilla JavaScript (hash router, custom CSV parser, localStorage, Web Speech API). No frameworks.

**Features:** Kandas > Sargas > Verses navigation, full-text search with Kanda filter and highlighting, Verse of the Day, bookmarks, listen (text-to-speech), copy verse, adjustable text size, continue reading, random verse, character pages with live mention counts, data chart, dark mode, keyboard shortcuts (/ to search, arrow keys for Sargas), reading-progress bar.

**Run:** open the folder in VS Code and use Live Server on `index.html`.

**Future ideas:** Sanskrit text, Uttara Kanda, Hindi translation, character relationship map, quiz mode.

## Images
Add pictures to `images/` (see `images/README.txt`).

## Deploy
GitHub Pages: push the project folder to a GitHub repo > Settings > Pages > Deploy from branch `main` / root.
Or drag the folder onto app.netlify.com/drop.
